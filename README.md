# BEAMxvs

A practice trainer for the Sony XVS-G1 switcher: the switcher's menu, page by page, and a practice panel laid out like the console, sharing one simulated switcher. Practise crosspoints, transitions, keys, macros and snapshots without touching a real switcher. By [BEAM Events](https://beamevents.com).

This repository only holds the **installers and updates**.

## Download
Get the latest version from **[Releases](https://github.com/BEAMevents/BEAMxvs/releases/latest)**:

- **BEAMxvs-x.y.z-mac-arm64.dmg** (Mac, Apple Silicon). Open it and drag BEAMxvs to Applications.
- **BEAMxvs-Setup-x.y.z.exe** (Windows) installs BEAMxvs. **BEAMxvs-Portable-x.y.z.exe** runs without installing.

The Windows installer isn't code-signed yet, so SmartScreen may warn on first launch: click **More info → Run anyway**.

## Updates
Click the version number at the top of the window. Installed copies check GitHub shortly after they start and every few hours, download new versions in the background and show **Update x.y.z ready**: click it, then **Install & restart**. It never installs by itself. On a Mac, keep BEAMxvs in Applications so it can update itself. The Windows portable version only links to the download page.

## Problems?
Use **Help → Send Diagnostics to BEAM…** (or the version number at the top). It sends BEAMxvs's log and a short status report to BEAM.
